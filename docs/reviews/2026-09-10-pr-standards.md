## Per PR

- **#14 — KEEP, high value.** All five suites pass. CI now aggregates all shell-suite statuses instead of running only smoke; update-block fixes remove actual baseline failures. No Standards finding.
- **#15 — KEEP, adapt README changes to redesign.** Host-neutral routing correction is useful. P2 README Develop command `for suite in tests/*.sh; do bash "$suite"; done` returns only the last suite's status, so a broken earlier suite can be reported as success. Use #14's status accumulator. Frontmatter parser intentionally enforces a narrow unquoted single-line format; keep that restriction explicit rather than claiming general YAML validation.
- **#16 — KEEP, high value.** Useful orphan discovery/indexing and a readable live-walkthrough index. No actionable Standards defect. The new audit checks local-directory indexing but not parent-to-child index reachability; a known coverage limit rather than reason to discard real routing fixes.
- **#17 — KEEP, fix token boundary.** P2 `tests/agents_yaml_audit.py:88`: substring check accepts `default_prompt: "Use $edit-funnel-old"` for skill `edit-funnel`; reproduced `audit_yaml(...) == []`. Match the complete skill token so renamed/stale prompts cannot pass the guard introduced to catch them.
- **#18 — KEEP.** Small coherent reference-frontmatter repair and focused checks. No actionable Standards defect; source verification for new compliance assertions belongs to Spec/research.
- **#19 — KEEP, moderate value.** New recovery routing and catalog row are coordinated. No blocking Standards finding. Catalog audit deliberately skips files with no table rows and compares sets, so it cannot detect removal of an entire summary table or duplicate table rows; this is a narrow drift detector, not complete catalog validation.
- **#20 — KEEP, high value.** Removes repeated workflow text while retaining the canonical instructions and fixes a hard-coded developer validator path. No actionable Standards defect; research update content remains subject to source verification.
- **#21 — CLOSE candidate as packaged; preserve create-funnel dedupe.** Possible Speculative Generality/Shotgun Surgery: `tests/viewport_canon_audit.py:34,68,85` duplicates the supposed canonical viewport set in code, treats every image-sized token as a viewport, and infers that any two distinct sizes mean a complete QA enumeration. A valid note comparing overflow at `375x667` and `393x852` is rejected for omitting the other two sizes. Any future image dimension needs a Python allowlist edit. Prefer explicit checks of the actual QA declaration; do not ban useful dimensions across all prose. This is a value/maintainability judgment, not an assertion the PR is unrelated.
- **#22 — KEEP, fix anchor checker before merging.** P2 `tests/reference_links_audit.py:61–95`: it slugifies link fragments as if they were heading text, so `[bad](#foo!)` passes against heading `# Foo` even though the literal fragment has no corresponding ID. It also loses plain underscores and duplicate-slug collisions. Reproduced `heading_slugs('# foo_bar\n# repeat\n# repeat\n# repeat-1\n')` returning `{'foobar','repeat','repeat-1'}`, missing distinct IDs. Decode and compare actual fragments; use GitHub-compatible heading slug generation. Broadening broken-link coverage itself is valuable.
- **#23 — KEEP.** Repairs two real stale path references and cross-links complementary QA docs. No blocking Standards finding. Possible Duplicated Code with #22's fenced-Markdown scanner; a shared small scanner is warranted only if both checks are retained and maintained.
- **#24 — KEEP, narrow provenance matching.** P2 `tests/copy_bank_tags_audit.py:70–75`: arbitrary prefix matching accepts invented `[headway-typo]` whenever `headway.md` exists; reproduced `tag_resolves('headway-typo', {'headway'}) is True`. This bypasses the intended source identity check. Use exact aliases for `headway-live`/`betterme` and reject arbitrary suffixes. FTC annotation relevance should be assessed independently from this fix.
- **#25 — CLOSE candidate as packaged; preserve verified research edit if supported.** Specialized ~400-line audit+tests for one checklist is a maintenance/value judgment. Concrete P2 `tests/design_qa_evidence_audit.py:31,170`: regex only matches already-known letters, making `unknown-evidence-tag` unreachable. A rule with `[F] [Z]` and a legend defining F returns no legend diagnostic; reproduced. It also reads only the first component of `[S/P]`. If retained, tokenize evidence tags independently from the allowed vocabulary and validate each component.

Remove `LIVE_EXCLUDED = {'nebula.md'}` when reconciling #24 rather than shipping a permanent blind spot. No justification to discard the useful source/path repairs.
