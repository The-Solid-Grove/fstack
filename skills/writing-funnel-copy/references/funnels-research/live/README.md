# Live Funnel Walkthroughs

Browser walkthroughs of funnels from the `funnels.xlsx` set, driven live through to the
paywall where reachable. Each file records the real entry promise, what the quiz
personalizes on, pricing/offer mechanics, and observed bugs. Consolidated patterns live in
[../00-LIVE-FINDINGS.md](../00-LIVE-FINDINGS.md); observed on-screen copy is consolidated
in [../copy/00-live-copy-swipe.md](../copy/00-live-copy-swipe.md).

Load only the files relevant to your vertical or mechanic. Files marked *skipped* document
why the funnel could not be walked (still useful as availability evidence — don't re-walk
without checking them first).
