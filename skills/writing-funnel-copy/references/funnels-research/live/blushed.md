## What was attempted (skip rationale)
Per the run's skip rule (down after one retry → skip + note why), I attempted to locate an equivalent live AI-companion web quiz funnel via the known "Blush AI" branded domains. None of them is a quiz-to-paywall funnel:

1. **blushedapp.com / www.blushed.app** — error page, no render (the actual target). Retried once; still errored.
2. **blushai.app** — Static SEO marketing landing page ("Experience Authentic Connections with Blush AI", "Your Personal AI Dating Simulator"). Its only CTA, **"Start Your AI Dating Journey Free"**, routes to `/login` — a hard email+password **Sign In / Sign Up** gate. No quiz, no onboarding funnel, no visible pricing. Blocked here per the no-account/no-password rule.
3. **blush.ai** — Pure app-download landing page. Headline **"AI dating. Real feelings"**, subhead "Blush is an AI-powered dating simulator that helps you learn and practice relationship skills in a safe and fun environment." Only CTAs are **App Store** and **Google Play** badges (with QR codes). No web funnel; conversion happens inside the native app, not on the web.
4. **blush-ai.net** — (per web search) a separate companion-preview marketing site; not the target product's funnel.

## Conclusion
Blushed's web quiz-to-paywall funnel was **not reachable during this run**. The branded alternatives either (a) error out, (b) gate immediately behind account creation, or (c) push users into the native iOS/Android app where the paywall lives — meaning the monetization is in-app (App Store / Play subscription) rather than a web checkout. This is itself a notable vertical pattern: several AI-companion products keep the paywall *inside the app* (App Store managed subscriptions, partly to navigate platform NSFW policy and payment rules) rather than exposing a web funnel.

## Vertical note (general, not from a live walk)
AI-companion funnels that *do* run on web typically gate on: character/persona selection, relationship-style preference, and a "your companion is being created" loader, then paywall a chat/NSFW unlock. None of that could be observed live here.
