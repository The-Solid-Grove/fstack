# Copy Swipe Files

Verbatim on-screen copy harvested per funnel, step by step — a swipe file for writing new
funnel copy, generating A/B variants, or seeding copy references.

## Start here

- **[00-COPY-BANK-by-screen-type.md](00-COPY-BANK-by-screen-type.md)** — the cross-funnel
  copy bank: lines from ~30 funnels (10 code-extracted + ~21 live) reorganized by screen /
  element type (hooks, feedback, loaders, paywall, guarantee, CTAs…), each tagged with its
  source funnel. Fastest way to find swipe copy for a specific screen; fall back to the
  per-funnel files below for full-flow context.

## Two sources

- **Code-extracted (exact):** copy pulled directly from the rag-catalog funnel source —
  complete and verbatim (headlines, option labels, CTAs, feedback, loaders, paywall,
  guarantee, FAQ, testimonials, microcopy). One file per funnel:
  - [headway-copy.md](headway-copy.md) · [12min-copy.md](12min-copy.md) ·
    [claimbee-copy.md](claimbee-copy.md) · [astroline-copy.md](astroline-copy.md) ·
    [betterme-chair-yoga-copy.md](betterme-chair-yoga-copy.md) · [keiki-copy.md](keiki-copy.md) ·
    [promova-copy.md](promova-copy.md) · [monivate-copy.md](monivate-copy.md) ·
    [addmile-copy.md](addmile-copy.md) · [blesse-copy.md](blesse-copy.md)
- **Live-observed (sampled):** [00-live-copy-swipe.md](00-live-copy-swipe.md) —
  consolidated copy captured during the browser walkthroughs of the `funnels.xlsx` set
  (21 funnels with copy; Blushed/Femia/Nebula/Plantin had none). This is what was observed
  on screen, not necessarily the full flow.

## Notes
- Code-extracted copy is authoritative for those 10 funnels; some strings are templated
  from user answers (flagged as dynamic with their static parts captured).
- Verbatim quirks were preserved on purpose (e.g. addmile's "8-WEEK PLA" typo, blesse's
  "2 Kings 20_5") — useful as real-world QA examples.
- Live copy may use placeholder personalization (the names/dates shown are from the test run).

~2,000 lines total. See `../00-MUST-DO-TRICKS.md` for how this copy maps to conversion patterns.
