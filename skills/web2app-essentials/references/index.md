# Web-to-Web Essentials

A practical guide to selling a subscription on the web and delivering its value in an app or browser.

**Acquisition → funnel → checkout → paid access → first useful action → retention**

Start with fit and economics. Then design the offer, connect payment to access, and test the whole journey before increasing spend.

## How to work through the course

Read in order for a first launch. For an existing funnel, start with the current bottleneck:

- **Unclear fit or budget:** lessons 2–3.
- **Visitors leave before buying:** lessons 5–7 and 10.
- **Buyers cannot start using the product:** lessons 4 and 8.
- **Purchase numbers look good but returns are weak:** lessons 3, 9, and 12.
- **Unclear next experiment or launch step:** lessons 11 and 13.
