# 1. What Web2Web is

Web2Web means acquisition and purchase happen on the web. The customer then uses the paid product in an app or browser.

**Ad → web funnel → web checkout → account and paid access → first useful action → renewal**

## Compare the models

| Model | Customer path | Where payment happens |
| --- | --- | --- |
| Native app acquisition | Ad → store → install → app onboarding | In the app |
| Web pre-sell | Ad → web explanation → store → app | In the app |
| Web2Web | Ad → web funnel → checkout → app or browser product | On the web |

For a mobile product, the last path is also called **web-to-app with web checkout**. Terminology varies across industry guides; identify the actual purchase and access path before comparing results.

## What changes

- **Acquisition:** the web journey exposes more pre-purchase behavior for analysis and campaign optimization. Consent, browser restrictions, cross-device use, and platform limits still create gaps.
- **Selling:** explain the problem, show a credible mechanism, and connect the offer to the ad promise before the customer uses the full product.
- **Economics:** compare total payment, billing, fraud, tax, and support costs—not just a quoted processing rate. Settlement timing and cash reserves also affect how quickly acquisition can grow.
- **Delivery:** connect a verified purchase to the correct account and paid access, including recovery when a redirect or app link fails.
- **Operations:** assign responsibility for renewals, cancellation, refunds, disputes, support, privacy, and applicable market/store rules.

Web checkout creates more control and more responsibility. It is not a universal exemption from app-store or subscription requirements; check the intended market and distribution model before launch.

## Judge the whole journey

A higher purchase rate can still produce worse economics if the buyers cancel early, request refunds, or cannot reach the product. Evaluate acquisition cost, net cohort value, cash payback, and the first useful action together.

Industry examples show how a funnel can work; they do not prove the economics of a different product. Use the short [industry reading list](index.md#industry-guides) for context and your own data for the decision.

## Apply it

Map one customer from ad click to first useful action. For each transition, record the owner, the linking ID, and the event that proves completion. Missing links reveal what must be built or verified.
