# Onboarding Experiments

*Distilled from course module 3.*

## Summary

After launching a funnel, growth comes in two phases: first make sure the funnel technically works everywhere users actually open it, then run a disciplined experiment loop. Compare step conversions against benchmarks to locate the weakest block (payment flow, paywall, or quiz), fix the most common failure modes, and A/B test one hypothesis at a time with ARPU as the primary metric. When traffic is thin or the audience is new, launch a separate funnel instead of an A/B test.

## Phase 1: Troubleshooting before optimizing

Verify the funnel works technically before searching for growth points:

- **In-app (native) browsers.** Check that the funnel opens and renders correctly in the Instagram, Facebook, and TikTok in-app browsers. Scroll behavior and back-to-feed navigation differ across these browsers and even across their versions.
- **Session recordings.** Watch real sessions in **Hotjar**.
- **Real payments.** Test the payment flow with real purchases; refund yourself afterwards. Refunds do not hurt your standing with payment providers.
- **Redirects.** If the payment flow includes a redirect (default hosted checkouts do), confirm the user is returned into the funnel after paying.

Only once everything works technically should you move on to growth work.

## Phase 2: Finding growth points

Work in this order:

1. **Analyze the funnel against benchmarks** — find which step underperforms.
2. **Payment flow.** If there are no large conversion drops between the second screen and the paywall, optimize pricing and the payment flow first.
3. **Paywall.** Typical problems:
   - No value in the offer; no match with the storytelling.
   - Weak visualization of the value.
   - Not enough warm-up: no personalization, timers, social proof, etc.
   - Weak CTA: a plain "Pay/Subscribe" button, poorly highlighted button.
4. **Quiz.** Typical problems:
   - Inconsistent storytelling; no match with the ad creative.
   - Irrelevant questions.
   - Not enough warm-up: no personalization, value/expected result never revealed.

(Creative experiments are treated separately, not as part of onboarding optimization.)

### Segment analysis

- Analyze quiz answers and conversion per answer segment.
- Adapt the whole flow — creative → funnel → paywall — to the best-converting segments.
- Feed the insights back into ad creatives.

### User research

- Deep audience understanding is what makes storytelling sell.
- Use in-depth interviews and JTBD research.
- Run UX tests of the funnel after major updates.
- Add audience-research questions directly into the funnel.

### What to test, ranked by frequency

1. **Quiz (most frequent focus).** Storytelling is hard to optimize but offers the most ways to lift conversion.
2. **Paywall:** offer, warm-up elements.
3. **Pricing and checkout** — roughly once per quarter.
4. **Funnel opening** — rarely.

### Finding new quiz topics

- Analyze competitors' creatives and funnels.
- Analyze user feedback.
- Analyze user behavior in the product. **Flo case study:** they noticed users engaging with sex-related content in the product → added dedicated questions to the funnel → conversion grew → analyzed the segment and built a separate funnel for it.

## Phase 3: How to run experiments

### Change granularity

- Test exactly as much as the hypothesis requires — usually a piece of communication spanning several screens, not a single word.

### Blocks to test separately

Do not combine point changes across these blocks in one test:

- Storytelling / quiz / feedback loops
- Main loaders
- Paywall
- Monetization (pricing, checkout)

Example sequencing: first test the quiz questions, then in a separate test add personalization to the paywall. Over time you'll develop your own patterns for what can be bundled.

### A/B test vs. launching a new funnel

| Use an A/B test when | Launch a new funnel when |
|---|---|
| There is enough traffic to measure quickly | Traffic is low |
| The change targets the current audience | Targeting a new audience (women/men, old/young) |
| | Making full competitor copies (creative + funnel + monetization) |

### A/B test setup rules

- **One hypothesis — one change — one test.** Don't add a checkout change to a paywall-messaging test.
- Split all traffic (or a portion) **50/50**.
- Split at the step **immediately before the change**.
- Run different tests on different geos (typically split into US / non-US country groups).
- **Metrics:**
  - Primary: **ARPU**
  - Secondary: CR, ARPPU, cancellation rate, refund rate

### Launching new funnels

Treat a new funnel exactly like a first launch:

- Separate URL
- Separate ad campaigns
- Separate pixel
- Optimize for ROAS
